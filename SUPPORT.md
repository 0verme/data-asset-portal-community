# Support / 支持说明

感谢使用数据资产门户。请选择正确的渠道，以便维护者和社区快速响应。

## 使用问题 / Questions

安装、配置、部署、使用方式和方案讨论请前往
[GitHub Discussions](https://github.com/0verme/data-asset-portal-community/discussions/categories/q-a)。

Please use GitHub Discussions for installation, configuration, deployment, usage, and design questions.

## Bug 与功能建议 / Bugs and feature requests

- 可稳定复现的缺陷：使用 Bug Report Issue Form。
- 明确的功能需求：使用 Feature Request Issue Form。
- 提交前请搜索现有 Issue 和 Discussion，并移除日志中的密钥、凭据和内部地址。

## 安全漏洞 / Security vulnerabilities

不要公开披露安全漏洞。请按 [SECURITY.md](./SECURITY.md) 通过 GitHub Private Vulnerability Reporting 私密提交。

Do not report vulnerabilities in public Issues or Discussions. Follow `SECURITY.md` and use GitHub Private Vulnerability Reporting.

## 响应时间 / Response time

本项目由社区维护，不承诺固定 SLA。维护者会尽力审阅有足够信息且属于 Community Edition 范围的问题。

This is a community-maintained project and does not provide a guaranteed response SLA.
